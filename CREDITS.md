# Credits

Every graphic in this game is a shape drawn with the browser Canvas 2D API. There are no sprites, fonts, sounds, or other files copied from a commercial game, and the page does not load anything from the network.

## Color

Category colors follow the Okabe–Ito palette, which is designed to stay distinct for the most common kinds of color blindness:

Okabe, Masataka, and Kei Ito. “Color Universal Design (CUD): How to make figures and presentations that are friendly to Colorblind people.” University of Tokyo, 2008. Palette listing: https://jfly.uni-koeln.de/color/

Neutrals for space, dug tunnels, dirt, hard rock, and the side panel are not part of that palette. Those tiles are also told apart by pattern: speckles on dirt, diagonal stripes on hard rock, hazard stripes on bedrock, and landing stripes plus the word PAD on the base.

## Code

The game is original code in this repository. It uses Canvas 2D and JavaScript that ship with the browser. No third-party library is vendored or downloaded.
